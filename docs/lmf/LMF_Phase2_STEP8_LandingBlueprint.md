# 🎯 가설 A (메인) — 옷장 가득한데 매일 똑같은 옷

## 기본 정보

- **타겟 페르소나**: 옷장 가득 차 있는데 매일 비슷한 옷만 입는 24~28세 여성
- **검증 가설**: "옷 100벌 있는데 매일 비슷한 옷만 입는 24~28세 여성에게, '내 옷장에서 새 조합 발견' VP를 ['100벌 가지고 있는데 매일 똑같은 옷' → '가진 옷으로 매일 새 룩' 시각적 Before/After]로 소구하면, 대기열 등록 전환율이 개선될 것이다."
- **핵심 약속 (1문장)**: "내가 가진 옷으로, AI가 한 번도 안 해본 새 조합을 찾아드립니다."
- **대표 소재 메시지**: "옷장에 100벌 있는데 매일 똑같은 옷만 입나요?"
- **주 로케일**: ko
- **감성 톤**: 공감/친근
- **비주얼 무드**: warm (크림/복숭아 — #FDEAE0, #FFF6F1)
- **예상 유입 경로**: 광고 클릭 (Meta)

## 고객 장면 요약 (6P)

- **도착 전 상황 (Problem)**: 옷장에 50~150벌 옷이 있는데 매일 입는 건 똑같은 10벌 안쪽. 새로 사도 비슷한 무채색만 또 사게 됨. 데이트·면접 전 30분~1시간 옷장 앞에서 헤맴.
- **도착 전 감정 (Emotion)**: 답답함 + 자기 짜증 ("또 비슷한 거 샀네"). 무력감 ("어차피 안 입을 것 같아").
- **유입 경로 (Action)**: 인스타그램/페이스북 피드 스크롤 중 "옷장에 100벌 있는데..." 후크에 클릭.
- **핵심 장애물 (Struggle)**: "어차피 안 어울리는 옷 사봤자" — 새 시도의 실패 두려움. + "있는 옷으로 뭘 어떻게 조합해야 할지 모름".
- **결정적 기능 (Attempt)**: AI가 내 옷장 사진을 읽고 한 번도 안 해본 조합을 발견해서 내 모습에 합성해 보여줌. 새 돈 없이.
- **기대하는 해피엔딩**: 친구가 "오늘 옷 다르네?"라고 물어보는데, 사실은 내가 1년 전에 산 옷장 구석의 옷. 매일 새 사람처럼 보이는데 새 옷은 안 샀음.

## 감정 아크 Peak 지정

- **Peak 섹션**: SolutionSection 1 (내 옷장에서 새 조합 발견) — 가장 강한 VP + Before/After 비주얼
- **End 섹션**: PostCTASection

## HeroSection 〈가설 종속 — A〉

**배지**: "🎨 베타 대기열 모집 중"

**헤드라인**: "옷장에 <span>100벌</span> 있는데, 매일 똑같은 옷만 입고 있나요?"
- 강조 (`<span>`): "100벌"
- 출처: s2-s6 카피 H1 그대로

**서브헤드라인**: "있는 옷도 조합이 어려워서 결국 어제 입던 옷.
AI가 내 옷장에서 한 번도 안 해본 새 조합을 찾아드려요.
새 옷 사지 않고도, 매일 새 룩."

**CTA 버튼**: "내 옷장 코디 받아보기"

**CTA 보조 텍스트**: "베타 무료 · 가입 30초 · 카드 필요 없음"

**히어로 통계** (검증 단계라 약속/기능 중심):
- `3가지` / 매일 받는 새 조합 추천 / 출처: 서비스 기획 약속
- `0원` / 옷 추가 구매 / 출처: 서비스 본질
- `30초` / 가입부터 시작까지 / 출처: 서비스 약속

**배경 스타일**: warm-light (#FDEAE0 → #FFF6F1 그라디언트)

**히어로 비주얼 명세**:
- 유형: 프론트엔드 목업 (CSS + 이미지 합성)
- 내용: 좌측에 가득 찬 옷장 일러스트 (위에서 본 뷰), 우측에 핸드폰 화면 안에서 AI가 추천한 조합 3장이 슬라이드되는 모습
- 에셋 현황: ❌ 미확보
- 제작 방법:
  1. 옷장 일러스트: 나노바나나/Imagen으로 생성 ("flat illustration of a packed wardrobe viewed from above, pastel colors, korean style")
  2. 핸드폰 목업: CSS로 iPhone 프레임 구현 + 내부에 합성 결과 이미지 3장
  3. 합성 결과 샘플: FASHN.ai 데모 사이트에서 3~5장 미리 생성
- 프롬프트 힌트: "옷장 사진 (top view, 50~100벌의 옷이 정리됨, 따뜻한 톤)"
- 대체안: 옷장 일러스트만 + "AI 추천 결과 준비 중" 텍스트 카드

**보조 CTA**: 없음 (단일 CTA로 집중)

**BMAP 분석**:
- **Motivation**: 광고 클릭으로 도착 → 중간 동기. Hero의 "100벌"이라는 구체 숫자로 즉시 자기 인식 강화
- **Ability 장벽**: 스크롤 없이 핵심 약속(가진 옷 + 새 조합)이 보여야 함. CTA 버튼이 첫 화면에 보여야 함
- **Prompt**: CTA 버튼은 체리 레드(#E73349)로 강한 대비. 보조 텍스트로 마찰 제거 ("카드 필요 없음")

## PainSection 〈가설 종속 — A〉

**배경**: light-warm (#FFF6F1) — 다크 배경 대신 따뜻한 톤 유지 (전체 무드 일관성)

**섹션 타이틀**: "이런 경험, 매일 하고 있지 않나요?"

**심리 원리**: 바넘 효과 — 인터뷰 B/C의 발화를 그대로 옮겨 "어, 이거 내 얘기네" 만들기

**Pain Points**:

1. **수치**: "90벌"
   **제목**: "매일 똑같은 10벌만 입어요"
   **설명**: "옷장은 가득한데, 구석 옷은 있는지도 모르고 매일 같은 자리에 손이 가요."
   **퍼소나 근거**: B "구석에 있는 옷은 있는지도 모르고" + C "막상 보면 새로운 게 있어요"
   **아이콘**: Lucide `Shirt` (반복 표시)

2. **수치**: "30분"
   **제목**: "데이트 전 옷장 앞에서 한참 헤매요"
   **설명**: "입었다 벗었다 30분, 결국 어제 입던 옷. 특별한 날인데 또 똑같이 입어요."
   **퍼소나 근거**: B "데이트 30분, 가장 예쁜 옷으로 신경 써서" + C "꾸미는 날 5분, 안 꾸미는 날 3분"
   **아이콘**: Lucide `Clock`

3. **수치**: "비슷한 옷 N개"
   **제목**: "또 비슷한 옷 샀어요"
   **설명**: "안 어울릴까 봐 결국 무채색 기본템만. 새 옷이지만 새 룩은 아니에요."
   **퍼소나 근거**: B "맨날 비슷한 느낌의 옷을 비슷한 가격대의 옷을 그렇게 사는 것 같아요"
   **아이콘**: Lucide `RefreshCw`

> 💡 **앵커링 전략**: 여기서 제시한 수치(90벌·30분·반복 구매)는 Solution 섹션에서 정확히 대조됨. Pain의 "90벌"은 Solution의 "옷장 전체 활용"으로, Pain의 "30분"은 Solution의 "30초 추천"으로 직접 대비.

# 🎯 가설 B (광범위) — 모델 사진 보고 후회한 적

## 기본 정보

- **타겟 페르소나**: 옷 살 때 모델 핏 보고 사봤다가 안 맞은 경험 있는 20~35세
- **검증 가설**: "옷 살 때 모델 핏 보고 사봤다가 안 맞은 경험 있는 20~30대에게, '내 체형으로 미리보기' VP를 [모델 사진 vs 내 모습 사진 좌우 비교]로 소구하면, 광고 클릭률(CTR)이 개선될 것이다."
- **핵심 약속 (1문장)**: "사진 한 장이면 AI가 내 체형으로 옷을 입혀서 보여드립니다."
- **대표 소재 메시지**: "모델 사진 보고 사봤다가 후회한 적, 있죠?"
- **주 로케일**: ko
- **감성 톤**: 발견/안도 (백화점 매장 사례 차용)
- **비주얼 무드**: warm + dark accent (대비 효과 강화)
- **예상 유입 경로**: 광고 클릭 (Meta) — 넓은 타겟

## 고객 장면 요약 (6P)

- **도착 전 상황 (Problem)**: 무신사·온라인 쇼핑몰에서 모델 핏 보고 옷 샀더니 내가 입었을 땐 완전 다른 옷. 키 작아서 기장 짧고, 어깨 좁아서 핏 안 살고. 반품도 귀찮아서 결국 구석에 처박힘.
- **도착 전 감정 (Emotion)**: 배신감 + 자책 ("내가 또 속았네"). 소비 후회.
- **유입 경로 (Action)**: 광고 피드 스크롤 중 "모델 사진 보고 사봤다가..." 후크 클릭. 또는 백화점에서 AI 피팅 경험 후 "이거 폰에서 안 되나?" 검색.
- **핵심 장애물 (Struggle)**: "이게 진짜 내 모습처럼 보일까?" — AI 합성 품질 불신.
- **결정적 기능 (Attempt)**: 전신 사진 한 장만 올리면 AI가 내 키·체형·비율 그대로 옷을 입혀서 보여줌. 사기 전에 확인 가능.
- **기대하는 해피엔딩**: 더 이상 옷 사고 반품하는 일 없음. 사기 전에 내 모습으로 미리 보고 결정. 옷장에 안 입는 옷이 쌓이지 않음.

## HeroSection 〈가설 종속 — B〉

**배지**: "🎨 베타 대기열 모집 중"

**헤드라인**: "<span>모델 사진</span> 보고 샀다가, 후회한 적 있죠?"
- 강조 (`<span>`): "모델 사진"
- 출처: s2-s6 카피 B-H1 그대로

**서브헤드라인**: "모델 핏은 모델이 입어서 예쁜 거예요.
내 키, 내 체형, 내 비율에 옷을 입혀보면 완전히 다른 모습.
사진 한 장이면 AI가 내 모습으로 미리 보여드립니다."

**CTA 버튼**: "내 모습으로 입어보기"

**CTA 보조 텍스트**: "베타 무료 · 사진 1장 · 1분 안에 결과"

**히어로 통계**:
- `1장` / 필요한 내 사진 / 출처: 서비스 기능
- `1분` / 가입부터 결과까지 / 출처: 서비스 약속
- `0원` / 사기 전 미리보기 / 출처: 서비스 본질

**배경 스타일**: warm-light + dark accent on visual

**히어로 비주얼 명세**:
- 유형: 프론트엔드 목업 (좌우 비교 컴포넌트)
- 내용: 좌측 패널 "모델이 입은 모습" (어두운 톤 배경), 우측 패널 "내가 입은 모습" (밝은 톤 배경 + 체크 아이콘). 좌측은 일반 모델 사진, 우측은 평범한 체형의 사람에게 합성한 결과
- 에셋 현황: ❌ 미확보
- 제작 방법:
  1. 모델 사진: 무신사 등에서 권리 제약 없는 모델 사진 (또는 AI 생성)
  2. 합성 결과: FASHN.ai 데모로 같은 옷을 평범한 체형에 합성
  3. 좌우 비교 컴포넌트: CSS Grid 2열로 직접 구현
- 프롬프트 힌트: "동일 옷 + 다른 체형 인물" 비교 가능한 샘플 3쌍 필요
- 대체안: 카드 1장으로 "모델 사진" 디스플레이 + 우측에 "→ AI 변환" 화살표 + 가려진 결과 + "내가 입은 모습 확인하기" 버튼

**BMAP 분석**:
- **Motivation**: "후회한 적 있죠?" 공감 후크로 즉시 동기 높임
- **Ability 장벽**: 좌우 비교가 한 눈에 들어와야 함. 모바일에서도 비교가 명확하게 보여야 함 (세로 스택 옵션 준비)
- **Prompt**: "내 모습으로 입어보기"는 매우 구체적 행동 동사 — 광고 카피와 일관성

# 🔧 Claude Code 구현 명령용 컨텍스트

## 듀얼 블루프린트 구현 전략

```
방식 A: 단일 페이지 + utm 파라미터 동적 분기 ★ 추천
  - 동일 URL: aicoordinate.vercel.app/
  - URL 쿼리: ?utm_content=h1_closet → 가설 A 버전
            ?utm_content=h1_fit    → 가설 B 버전
  - utm 미입력 시 기본값: 가설 A
  - Hero/Pain/CTA만 컴포넌트 swap, 나머지 동일
  - 장점: SEO 단일, 구현 단순, Supabase 추적 단순

방식 B: 두 페이지 분리
  - aicoordinate.vercel.app/closet (가설 A)
  - aicoordinate.vercel.app/fit (가설 B)
  - 광고 utm으로 각 URL 직접 지정
  - 장점: 코드 명확
  - 단점: SEO 분산, 공통 컴포넌트 변경 시 양쪽 수정 필요

▶ 권장: 방식 A (단일 페이지 + URL 쿼리 분기)
```
