# ⚠️ 운영 시 주의사항

## 1. Meta 광고 정책 체크
- "AI" 자동 추천 광고는 일부 카테고리에서 추가 검수 받을 수 있음
- "내 체형" "내 사진" 등 신체 관련 표현은 디스크리미네이션 정책 트리거 가능 → "내 모습"이 더 안전
- 광고 거부되면 즉시 대체 카피 준비해둘 것

## 2. 카피 길이 가이드
- 인스타그램 피드 본문: 첫 줄(125자)이 미리보기로 보임 → 후크는 첫 줄에
- 페이스북 피드 헤드라인: 25자 권장 (잘림 방지)
- 스토리/릴스: 텍스트 최소화, 비주얼 우위

## 3. utm 추적 검증
캠페인 시작 전 각 utm 파라미터로 접속해서 Supabase `waitlist.source` 컬럼에 정확히 기록되는지 1회 테스트 필수.

```sql
-- 검증 쿼리 예시
SELECT source, COUNT(*)
FROM waitlist
WHERE created_at > NOW() - INTERVAL '1 day'
GROUP BY source;
```

## 4. 첫 3일 모니터링 포인트
- CPC > 800원: 카피·이미지 문제 가능성, 비주얼 교체 고려
- CTR < 1%: 후크 약함, 헤드라인 교체
- 랜딩 CVR < 3%: 광고가 아니라 랜딩 문제, 광고 늘리지 말고 랜딩 수정

## 5. 비주얼 제작이 가장 큰 변수
- AI 합성 결과 샘플 이미지 4~6장이 필요
- 좋은 합성 샘플 = 광고 성공의 50% 이상
- → 제작 시간 확보가 캠페인 일정의 핵심 변수
