# STEP 0: 브랜드 컨텍스트

## 브랜드/서비스
- **브랜드명**: AI Coordinate
- **도메인**: aicoordinate.vercel.app
- **한 줄 소개**: 내가 가진 옷으로 어울리는 조합을 AI가 골라주고, 내 모습에 합성해서 보여주는 서비스
- **단계**: 가설 검증 단계 (랜딩 페이지만 배포, MVP는 미개발)

## 핵심 기능 3가지
1. **AI 자동 코디 추천** — 내 옷장 안에서 어울리는 조합 1~3개 선별 (Claude API)
2. **가상 피팅 합성** — 내 전신 사진에 그 조합을 입혀서 결과 이미지 생성 (FASHN.ai VTON)
3. **자동 옷장 관리** — 옷 사진 업로드 시 카테고리/색/패턴/계절 자동 태깅

## 타겟 (전략)
좁히지 않고 넓게 가면서 광고 반응으로 학습. 인터뷰에서 드러난 잠재 세그먼트(STEP 2에서 퍼소나로 정리):
- 패션 고관여 매니아 (제외)
- 저관여 다소유자 (메인)
- 자신감 부족형 (서브)

## 보유 데이터
- ✅ 유저 인터뷰 4건 (28남, 24여, 25여, 22남)
- ✅ 랜딩 페이지 인프라 (Amplitude + Session Replay + utm 자동 수집)
- ❌ 경쟁사 리뷰 / 광고 성과 / 기존 가입자 데이터 — 없음

## 경쟁사 & 차별점
| 구분 | 한계 |
|---|---|
| 가상 피팅 단독 | 옷은 사용자가 직접 골라야 함 |
| 옷장 관리 단독 (에이클로젯 등) | 합성 결과를 보여주지 않음 |
| 백화점 직원 비공식 AI (인터뷰 1번 사례) | 매장에서만, 일회성 |

**차별 가설**: "내 옷장" + "AI 조합 추천" + "내 모습 합성" 세 가지를 묶은 첫 서비스

## 광고 캠페인 설계 (확정안)
```
브랜드: AI Coordinate
캠페인 목적: 시장 반응 1차 확인 (Spike Test)
채널: Meta (Instagram + Facebook)
예산: 30만원
구조: 일 6만원 × 5일, 단일 광고세트, 소재 2개
KPI: 대기열 등록수 (총량) + Session Replay 정성 관찰

목표 라인:
- 🚨 적신호:    등록 10명 이하 — 가설/소구점/랜딩 중 어딘가 심각한 문제
- ⚠️ 약함:      등록 10~30명 — 시그널은 있으나 약함, 다음 라운드 필요
- ✅ 정상:      등록 30~60명 — 시장 반응 확인, 예산 추가 정당화
- 🚀 강함:      등록 60명+   — 빠르게 추가 예산 확보 권장

예상 CPA: 5,000~10,000원
```

**안전장치**:
1. 첫날~3일 차 일 5만원 시작 → 어처구니없는 소재로 돈 태우는 사고 방지
2. CPA 8,000원 넘으면 일시 정지 → 소재 점검 후 재집행
3. 랜딩 CVR 3% 미만이면 광고가 아니라 랜딩 문제 → 광고 늘리지 말고 랜딩 수정

## 🎯 퍼소나 1: "옷장 가득 차 있는데 매일 비슷한 옷만 입는 24살"

> **옷이 100벌인데 새로운 시도가 두려워서 어제 입던 옷만 또 입는 사람**

- **상황**: 20대 중반 여성. 옷에 관심은 있어서 꾸준히 사 모았더니 옷장이 가득. 구석에 뭐가 있는지 정확히 모름. 새 옷을 사도 결국 비슷한 무채색·기본템만. 데이트나 면접에서는 30분~1시간을 고민하지만 결국 "무난한" 선택.
- **페인포인트**:
  - "맨날 비슷한 느낌의 옷을 비슷한 가격대의 옷을 그렇게 사는 것 같아요" (B)
  - "막상 보면 새로운 게 있어요" / "구석에 있는 옷은 있는지도 모르고" (B, C)
  - "사봤자 지금 이 순간에만 마음에 들고 안 입을 것 같아서요" (B)
  - "특별하고 싶을 때 다 비슷한 옷만 있으니까 아쉬운 건 있는 것 같아요" (B)
- **현재 대안**: 옷장 앞에서 30분 입었다 벗었다 / 비슷한 옷 또 구매 / 안 입는 옷 구석 방치 / 당근 판매 시도(실패)
- **결정적 동기**: "내가 가진 옷들 중에서, 내 체형에 입혀진 모습으로, 새로운 조합을 보여주면"

# STEP 3: Use Case Map

## 🗺️ Use Case Map 1: 옷장 가득 24여

1. **Problem**: 100벌 가까운 옷 가지고 있는데 매일 입는 건 똑같은 10벌 안쪽. 새 조합 시도 → 머릿속 매칭 안 됨 → 새 옷 사도 비슷한 것만. 중요한 자리 30분~1시간 고민 → 결국 무난.
2. **Persona**: 24~28세 여성 직장인/사회 초년생, 옷 50~150벌, 구석 옷 망각, 새 시도 회피
3. **Alternative & 한계**:
   - 옷장 앞 30분 입었다 벗었다 → 시간만 가고 어제 입던 옷
   - 무신사 등 온라인 → "비슷한 것만 또 사게 됨" + 모델 핏 괴리
   - 당근마켓 판매 → "잘 안 팔려요"
   - 옷 대여 → "비싸고 귀찮음"
   - 인스타·핀터레스트 → 영감만, 내 옷장 매칭 불가
4. **Why (★★★★★)**: **"내가 이미 가진 옷 안에서, AI가 새로운 조합을 발견해서, 내 체형으로 입혀진 모습을 보여준다"**

   | 차원 | 옷장 관리 앱 | 가상 피팅 앱 | 룩북/핀터레스트 | **AI Coordinate** |
   |---|---|---|---|---|
   | 내 옷 등록 | ✅ | ❌ | ❌ | ✅ |
   | AI가 조합 추천 | ❌ | ❌ | ❌ | ✅ |
   | 내 모습 합성 | ❌ | ✅ (구매옷만) | ❌ | ✅ |
   | 새 돈 안 듦 | ✅ | ❌ | ✅ | ✅ |

   경쟁사가 따라하기 어려운 이유: 옷장 관리 앱은 "정리"가 본질, 가상 피팅 앱은 "구매 전환"이 본질. 우리는 "보유 자산 재활용"이라는 다른 본질.
5. **Frequency**: 매일(아침) + 주 2~3회(약속) + 월 1~2회(중요한 자리) + 계절 전환기(연 4회) → **고빈도**
6. **Use Cases**:
   - 데이트 전날 밤: "내일 데이트룩으로 3가지만" → AI 추천 → 한 번도 안 해본 조합 발견
   - 환절기 아침: "오늘 18도 맑음" → AI 추천 → "아 이 가디건 있었지!"
   - 면접 전날: "단정한데 정장 아닌 조합" → 옷장 깊은 곳 발견

## 🗺️ Use Case Map 2: 자신감 없는 22남

1. **Problem**: 내가 고른 옷이 어울리는지 객관적 확인 불가. 핀터레스트 영감도 내 체형 적용 미지수. 부모·여동생 항상 부정적. 결국 무채색 기본템만 반복.
2. **Persona**: 20~25세 남성 대학생/사회 초년생, 옷 관심 생겼으나 자신감 부족, 외부 피드백 의존
3. **Alternative & 한계**:
   - 핀터레스트 → "광고처럼 느껴짐" + 내 체형 적용 불가
   - 부모·여동생 피드백 → 부정적/취향 충돌
   - 무채색·무난템 반복 → 안전하지만 발전 없음
   - 온라인 쇼핑몰 모델 핏 참고 → 키 181인데 기장 짧음
   - 오프라인 직접 입어보기 → 시간·에너지 소모
4. **Why (★★★★★)**: **"AI가 객관적으로 어울리는 조합을 골라주고, 내 체형에 입혀서 보여준다. 가족 잔소리 없이도 검증된다."**
   - 객관적 판단 (가족 주관 대신 AI)
   - 시도 비용 0 (매장·구매 없이 미리 확인)
   - 사적 공간 (부모님 안 보는 곳)
5. **Frequency**: 매일 아침(저관여) + 주 1~2회(약속) + 분기 1~2회(새 옷 구매) + 연 1~2회(스타일 변경) → 빈도 낮지만 결정 부담 큼
6. **Use Cases**:
   - 핀터레스트 영감 직후: 스크린샷 + 내 옷장 → 비슷한 조합 합성
   - 옷 사기 전 사전 검증: 사고 싶은 옷 + 내 옷장 → 어울리면 구매
   - 가족 모임/소개팅: "단정한데 정장 아닌 조합" → 자신감 있게 결정

# STEP 4: VP(Value Promise) 도출

6개 VP를 모두 도출했고, ICE에서 상위 3개를 가설로 활용. 1·2·3순위는 굵게.

## VP #1 — 보유 자산 재활용 🥇

- **제약**: 옷 100벌인데 매일 비슷한 것만 입는다. 새 옷 사기는 두렵고, 있는 옷은 활용을 못 한다.
- **기능**: 사용자가 등록한 옷장 안에서 AI가 새로운 조합을 발견해 추천
- **동기**: 새 돈 들이지 않고 새로운 모습을 보고 싶다
- **VP 문장**: "옷장은 꽉 찼는데 매일 똑같은 옷만 입는 사람에게, AI가 가진 옷으로 새 조합을 발견해준다."
- **핵심 언어**: "내 옷장에서 새로운 조합" / "있는 옷으로 새 코디" / "새 옷 안 사도 새 룩"

## VP #2 — 내 체형으로 시뮬레이션 🥈

- **제약**: 모델 핏이랑 내 몸이 달라서 사진을 봐도 어떻게 보일지 모른다.
- **기능**: 내 전신 사진에 옷을 합성해 실제 입은 모습 생성
- **동기**: 사기 전에·입기 전에 내가 입은 모습을 보고 싶다
- **VP 문장**: "모델 핏 보고 사봤더니 안 맞은 적 있는 사람에게, 내 체형 그대로 입어본 모습을 보여준다."
- **핵심 언어**: "내 모습으로 입어보기" / "모델 말고 내가 입었을 때" / "내 체형으로 미리보기"

## VP #3 — 객관적 검증 🥉

- **제약**: 내가 골랐는데 어울리는지 확신이 없다. 부모님·동생한테 물어보면 뭐라고 한다.
- **기능**: AI가 체형·퍼스널컬러·TPO 종합 판단해 어울리는 조합만 선별
- **동기**: 객관적인 "어울림" 판단을 받고 싶다 (가족 잔소리 없이)
- **VP 문장**: "어울리는지 확신이 안 서서 무채색만 입는 사람에게, AI가 객관적으로 어울리는 조합을 골라준다."
- **핵심 언어**: "AI가 골라줘" / "어울리는지 확인" / "객관적인 코디 조언"

## VP #4 — 결정 시간 단축

- **제약**: 데이트나 중요한 자리 전에 옷 고르느라 30분~1시간 30분 걸린다.
- **기능**: 오늘 날씨 + TPO + 옷장 자동 매칭해 3가지 조합 즉시 제시
- **동기**: 옷장 앞에서 헤매는 시간을 줄이고 싶다
- **VP 문장**: "옷장 앞에서 30분 헤매는 사람에게, AI가 오늘 입을 옷 3가지를 즉시 제안한다."
- **핵심 언어**: "오늘 뭐 입지 30초 해결" / "옷장 앞 30분 끝" / "출근 5분 코디"

## VP #5 — 잊고 있던 옷 재발견

- **제약**: 구석에 있는 옷은 있는지도 모르고, 청소할 때 발견한다.
- **기능**: 등록된 모든 옷을 AI가 항상 인식하고 조합 시 빠짐없이 고려
- **동기**: 가진 옷을 빠짐없이 활용하고 싶다
- **VP 문장**: "구석에 있는 옷은 까먹고 안 입는 사람에게, AI가 옷장 전체를 기억하고 활용해준다."
- **핵심 언어**: "잊고 있던 옷 다시 입기" / "옷장 전체가 살아난다" / "구석 옷도 빛 본다"

## VP #6 — 새 시도의 안전한 실험

- **제약**: 새 옷 사봤자 안 입을 것 같아서 비슷한 것만 산다. 색이 튀는 게 두렵다.
- **기능**: 가상 피팅으로 새 조합·새 스타일을 미리 확인
- **동기**: 실패 부담 없이 새 시도를 해보고 싶다
- **VP 문장**: "새 시도가 두려워 안전한 옷만 입는 사람에게, 실패 부담 없이 새 스타일을 미리 시뮬레이션한다."
- **핵심 언어**: "실패 없는 새 시도" / "사기 전에 미리 입어보기" / "안전한 패션 실험실"

| VP #1 (보유 자산 재활용) | ⭐⭐⭐⭐⭐ | B+C 명시 | ⭐⭐⭐⭐⭐ (유일) | ⭐⭐⭐⭐⭐ | 🥇 1순위 |

# STEP 5: 소구점 가설 + ICE

## 가설 5개

### 가설 1 (퍼소나1 × VP1) ⭐ 메인 베팅
> "옷 100벌 있는데 매일 비슷한 옷만 입는 24~28세 여성에게, '내 옷장에서 새 조합 발견' VP를 ['100벌 가지고 있는데 매일 똑같은 옷' → '가진 옷으로 매일 새 룩' 시각적 Before/After]로 소구하면, 대기열 등록 전환율이 개선될 것이다."

### 가설 2 (전체 × VP2) ⭐ 광범위 후크
> "옷 살 때 모델 핏 보고 사봤다가 안 맞은 경험 있는 20~30대에게, '내 체형으로 미리보기' VP를 [모델 사진 vs 내 모습 사진 좌우 비교]로 소구하면, 광고 클릭률(CTR)이 개선될 것이다."

### 가설 3 (퍼소나2 × VP3)
> "어울리는지 자신 없어서 부모/동생에게 물어보는 20~25세 남성에게, 'AI가 객관적으로 골라줌' VP를 ['엄마가 그렇게 입지 말라고 한다 → AI는 안 잔소리한다']로 소구하면, 대기열 등록 전환율이 개선될 것이다."

### 가설 4 (퍼소나1 × VP4)
> "데이트 전 30분~1시간 옷장 앞에서 헤매는 20대 여성에게, '결정 시간 단축' VP를 ['오늘 데이트 30초 만에 옷 결정' 빠른 시연 영상]으로 소구하면, 대기열 등록 전환율이 개선될 것이다."

### 가설 5 (퍼소나1 × VP6)
> "안 어울릴까 봐 비슷한 옷만 사는 20대 여성에게, '실패 없는 안전한 시도' VP를 ['새 옷 사기 전 미리 입어보기' 합성 시뮬레이션]으로 소구하면, 광고 클릭률(CTR)이 개선될 것이다."

| **가설 2** | 전체 20~30대 | VP#2 내 체형 미리보기 | 9 | 9 | 7 | **16** | 🥈 |

### 스코어링 근거 (주요 가설)

**가설 1 (I=9, C=8, E=8 → 17)**
- I=9: 페인 강도 + 우리만의 차별점 + 시장 미존재 = 큰 반응 기대
- C=8: 인터뷰 2명(B+C) 직접 발화, 단 4명 표본의 한계
- E=8: "100벌 vs 매일 똑같은 옷" 모순 후크 강력, 비주얼 명확

**가설 2 (I=9, C=9, E=7 → 16)**
- I=9: 광범위 페인 (성별·나이 무관 클릭 유도)
- C=9: 인터뷰 3명(A·C·D) 언급, **A의 매장 사례에서 실제 결제 의사 검증**
- E=7: 좋은 합성 결과 비주얼 필요 (샘플 제작 필요)
