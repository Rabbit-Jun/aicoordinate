# 포팅 시 필수 반영 수정사항 (디자인 HTML에 미반영 상태)

## 오탈자 (모든 위치 일괄)
1. "상상이 안가서" → "상상이 안 가서"
2. "쉽지않죠" → "쉽지 않죠"
3. "캐쥬얼" → "캐주얼"
4. "클레식" → "클래식"
5. "같은 코디, 다른느낌" → "같은 코디, 다른 느낌"

## 기타
6. 폰 목업 상태바의 "U⁺" 통신사 표시 제거 → 시간만 (예: 9:41)
7. 색상은 디자인 HTML의 hex를 그대로 쓰지 말고 기존 디자인 토큰
   (accent/foreground/muted/surface/border/background)으로 치환
